## How to edit this site

Du brauchst keinen eigenen Entwicklungscomputer oder ein Terminal.

1. Öffne dieses GitHub-Repository im Browser.
2. Öffne die Datei, die du ändern möchtest.
3. Klicke auf das **Stift-Symbol (Edit)**.
4. Ändere den gewünschten Text, Link oder Code.
5. Klicke auf **Commit changes**.
6. Netlify veröffentlicht die Änderung nach dem verbundenen Deployment automatisch.

Für grössere Änderungen kann AI beim Erstellen oder Ändern des Codes helfen. Immer zuerst prüfen, welche Datei geändert werden soll, und danach die Änderung in GitHub committen.
